# 赛项一 · 医保回流药资金线索智能研判

面向办案人员的研判智能体：**数据治理 → 关系分析 → 图谱生成 → 线索报告**，并支持对关键判断进行人工复核。

- 赛题要求：`第三届全国公安院校大数据智能警务挑战赛.docx`
- 原始取证数据：`data/赛项一：竞赛数据/`（857 个数据文件，414 MB，**只读，程序绝不改写**）
- 代码：`app/`　·　输出：`output/`　·　依赖：`libs/`（离线附带）+ `app/requirements.txt`
- 运行环境：**Linux**（Python 3.10+，已装中文字体；见"部署与操作说明"第 1 节）

## 一分钟上手

```bash
cd ~/智慧建模
python3 -m pip install -r app/requirements.txt

# 方式一：网页工作台（推荐）——启动后在"⑥ 导入与处理"里导入数据、点"开始处理"，
# 整条分析链路（整理→实体→指标→筛查→图谱→报告）都在界面里跑，进度实时可见。
python3 app/server.py --port 8000

# 方式二：命令行跑完整分析（不使用界面时）
python3 app/pipeline.py tidy entities features screen graph report
python3 app/pipeline.py excel
```

分析内核（不含 Excel 导出）在 292.9 万行数据上约 **11 分钟**。

## 三个刻意的设计决定

1. **不凭空补齐**：空值留空并登记；列数错位按位置映射、缺失列留空；身份只允许掩码等价归一，不推断被掩码位。
2. **同群分位而非绝对阈值**：本批数据夜间交易占比中位数仅 1.2%、提现率中位数已达 0.55，绝对阈值会让 165/169 个对象被判成同一角色。
3. **平台操作与人际流转分开**：提现/充值/退款/手续费是账户与平台之间的动作，混入角色推断会把 13 万级对手方误判为"下游"，并稀释开药人信号。

## 大模型对话（可选）

对话查询已接入平台的 `/chat/completions` 大模型接口，做成**带工具调用的研判智能体**：

回答中的金额/笔数/来源行号全部来自查询结果，并显示工具调用链供审计。

## 交付完整性自检

`excel` 阶段结尾会把"导出的流水总行数"与库中 `txn` 行数逐一比对，不一致就抛错而不是静默少行。
本轮结果：**308 个工作簿 / 2,928,834 行 = 库中 2,928,834 行**。
这个自检曾抓到真实缺陷：4 个账号的掩码归一后只剩星号（`*`/`**`/`***`/`****`），文件名塌成同一个被互相覆盖，静默丢了 16 行；现按来源目录名兜底并对同名续编 `_2/_3/_4`。
